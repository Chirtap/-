# 我的个人主页

## 分支与合并
分支就像是在主线上分出来的“平行时空”，可以在里面随意修改代码而不会影响主线；合并就是把平行时空的改动拉回主线。

## 许可证
本项目使用 MIT 许可证。选择它是因为它足够宽松，允许别人自由使用、修改我的代码，只要保留我的版权声明就行。

## AI 给我的错误信息
AI 曾建议我用 `<marquee>` 标签让文字滚动，但我查了资料发现这个标签早已被 HTML5 废弃，所以我没有使用。

## 关键代码逻辑解释
1. 主页的卡片使用了 CSS 的 `flex` 布局，这样在不同屏幕尺寸下卡片会自动换行排列。
2. 简历页面使用了 `@media print` 媒体查询，让打印成 PDF 时排版干净。
