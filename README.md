# 我的个人主页 & 2048 游戏项目

## 一、通用素养（任务三）

### 分支与合并
分支就像是在主线上分出来的“平行时空”，可以在里面随意修改代码而不会影响主线；合并就是把平行时空的改动拉回主线。

### 命令行常用命令说明
- `cd`：进入指定文件夹（比如 `cd 2048_game` 就是进入该文件夹）
- `ls`：列出当前文件夹里的所有文件和文件夹
- `mkdir`：新建一个文件夹（比如 `mkdir new_folder`）
- `git add`：把修改的文件添加到“暂存区”，准备提交
- `git commit -m "说明"`：把暂存区的修改保存为一个版本，并写上说明
- `git push`：把本地的提交上传到 GitHub 远程仓库

### 许可证
本项目使用 MIT 许可证。选择它是因为它足够宽松，允许别人自由使用、修改我的代码，只要保留我的版权声明就行。

### AI 给我的错误信息
AI 曾建议我用 `<marquee>` 标签让文字滚动，但我查了资料发现这个标签早已被 HTML5 废弃，所以我没有使用。

### 关键代码逻辑解释（防纯粘贴）
1. **主页卡片布局**：使用了 CSS 的 `flex` 布局。这样在不同屏幕尺寸（手机/电脑）下，卡片会自动换行排列，不需要写死宽度，实现响应式设计。
2. **简历打印优化**：使用了 `@media print` 媒体查询。专门针对打印优化了字体大小和边距，确保打印成 PDF 时排版干净、不会分页断裂。
3. **2048 游戏移动逻辑**（额外补充）：每次按下方向键，程序会先尝试合并相同数字，再移动方块，最后在空白处生成新方块。合并时从边缘向中间遍历，确保不会遗漏任何可合并的方块。

## 二、2048 游戏（任务四）

### 阶段一（可玩版本）
- **实现方式**：使用 HTML + CSS + JavaScript 完成，所有代码在一个文件里。键盘方向键控制方块滑动，相同数字合并累加分数，游戏结束或胜利有弹窗提示。
- **验证方式**：手动操作玩了多局，确认得分正常累计、2048 胜利判定准确、无法移动时游戏结束判定正常、重置按钮能完全清空棋盘。

### 阶段二（AI 自动演示）
- **实现方式**：新增“AI 自动演示”按钮，点击后 AI 采用贪心评分算法，每次模拟上下左右移动，优先选择让空格最多或最大数字留在角落的方向。
- **验证方式**：连续运行 AI 演示 3 次，每次都能稳定合出 1024 方块（其中一次合出了 2048），证明 AI 策略有效。
